# mini-online-stor

Бұл — тауарларды интернет арқылы сататын шағын сайт. 

* Клиенттер тіркеліп, сайтқа кіре алады.
* Тауарларды іздеп, санаттар бойынша (мысалы: киімдер, телефондар) сүзгіден өткізе алады.
* Ұнаған тауарды Себетке (Корзина) салып, санымен бағасын есептей алады.
* Сатып алу үшін тапсырыс бере алады.
* Дүкен иесі (Админ) жаңа тауар қосып, ескісін өшіре алады.

1. **Басты бет:** Дүкеннің жарнамасы және ең өтімді тауарлар тұрады.
2. **Каталог беті:** Барлық тауарлар тізіліп тұратын орын.
3. **Тауардың жеке беті:** Бір тауарды басқанда ашылатын, оның сипаттамасы мен суреті бар бет.
4. **Себет (Корзина) беті:** Сатып алуға таңдалған тауарлар тізімі.
5. **Тапсырыс беру беті:** Мекенжай мен телефон нөмірін жазатын бет.
6. **Админ панель:** Дүкенші тауарларды басқаратын құпия бет.
